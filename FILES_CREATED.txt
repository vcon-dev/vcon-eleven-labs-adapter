  INTERACTIVE TOOLS (2 new files)
================================================================================

1. test_live.py (10K)
   - Interactive menu-driven tool
   - Prompts for API key
   - Tests connection to ElevenLabs
   - Lists your agents
   - Checks for conversations
   - Processes conversations to vCons
   - Verifies created files
   - Full end-to-end test option
   → RECOMMENDED: Run this after setup

   Usage: python3 test_live.py
   Features:
     - Option 1: Test API connection
     - Option 2: Check conversations
     - Option 3: Process conversations
     - Option 4: Verify output
     - Option 5: Full test (all steps)
     - Option 6: Exit

2. setup_live_test.sh (executable, 2K)
   - One-time setup script
   - Activates virtual environment
   - Installs/checks dependencies
   - Creates config.yml
   - Creates vcons directory
   → Run once: bash setup_live_test.sh
