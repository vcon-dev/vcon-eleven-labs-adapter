================================================================================
  WHAT TO EXPECT
================================================================================

First Run (without conversations):
  - API connection test should succeed
  - You'll see your agents listed
  - No conversations yet (normal, place a test call first)

After Placing Test Calls:
  - Call your agent's phone number
  - Have a conversation (30+ seconds)
  - Wait 1-2 minutes for processing
  - Run test again
  - Adapter will create vCon files

Success Indicators:
  - Files appear in vcons/ directory
  - File size > 1 KB
  - Contains conversation data with parties and dialog
  - adapter.log shows successful processing
